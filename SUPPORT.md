# Support

Choose the right channel so reports can be handled quickly.

- **Questions and ideas:** GitHub Discussions, when enabled
- **Bugs:** bug report issue form
- **Feature requests:** feature request issue form
- **New product requests:** app request issue form
- **Copyright or removal:** follow [DMCA.md](DMCA.md)
- **Sensitive privacy or security issue:** follow [SECURITY.md](SECURITY.md), never a public issue

Open Flow is community maintained. Response times are not guaranteed.
