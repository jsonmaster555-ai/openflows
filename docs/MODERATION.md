# Moderation Guide

This guide helps maintainers review submissions consistently.

## Review order

1. Check for exposed people, personal data, private content, and secrets.
2. Check that the contributor had authorized access.
3. Check for prohibited or high-risk content.
4. Check image quality and accuracy.
5. Validate metadata and file placement.
6. Check for duplicates.

Privacy and safety come before completeness.

## If personal data is found

Do not quote, repost, or describe the exposed information in a public review. Restrict the contribution when possible, contact the contributor privately if needed, and follow the repository's security process.

Because Git history can preserve deleted files, removing the current file may not fully remove the original. Escalate repository-history cleanup to a maintainer with the necessary access.

## Review outcomes

- Approve
- Request changes
- Close as duplicate
- Reject for policy reasons
- Temporarily restrict for private review
- Remove after publication

Keep moderation notes factual and avoid unnecessary personal details.
