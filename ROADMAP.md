# Roadmap

The roadmap describes direction, not a promise or deadline.

## Phase 0: Foundation

- [x] Project documentation
- [x] Privacy-first submission rules
- [x] Initial metadata schemas
- [x] Issue and pull request templates
- [ ] Maintainer contact and private security reporting
- [ ] Automated schema validation
- [ ] Image size and duplicate checks

## Phase 1: Repository library

- [ ] First verified product entries
- [ ] Screen and flow naming standard
- [ ] Contributor guide testing
- [ ] Metadata linter
- [ ] Preview generation for pull requests
- [ ] Moderation labels and review queue

## Phase 2: Website

- [ ] Product pages
- [ ] Screen browser
- [ ] Flow viewer
- [ ] Search and filters
- [ ] Responsive layouts
- [ ] Accessible keyboard navigation
- [ ] Ad placements that do not block the core library

## Phase 3: Community platform

- [ ] Accounts and contributor profiles
- [ ] Web submission workflow
- [ ] Moderation dashboard
- [ ] Version history
- [ ] Duplicate detection
- [ ] Reports and removal requests

## Phase 4: Developer access

- [ ] Read-only public API
- [ ] API documentation and limits
- [ ] MCP server
- [ ] Design and coding tool integrations
- [ ] Stable dataset exports when legally and operationally appropriate

## Non-goals

- Hosting personal profiles or conversations
- Becoming a general image-sharing service
- Republishing private or leaked interfaces
- Bypassing paid services or access controls
- Adding unrelated design generators to the core library
