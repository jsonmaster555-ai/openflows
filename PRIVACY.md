# Privacy

Open Flow should collect as little personal information as practical.

## Repository contributions

GitHub publicly records usernames, commits, issues, pull requests, comments, and other activity according to GitHub's own policies. Do not include personal information in commit messages, metadata, screenshots, issues, or pull requests.

## Screens and flows

Screens and flows must be anonymized before submission. Open Flow does not need the identity of the people shown in an interface.

Read [SUBMISSION_GUIDELINES.md](SUBMISSION_GUIDELINES.md) for the required redaction rules.

## Future website

Before Open Flow launches accounts or direct uploads, the project should publish a separate website privacy notice explaining:

- What data is collected
- Why it is collected
- How long it is kept
- Which service providers process it
- How users can request access, correction, or deletion where applicable
- How abuse prevention, logs, analytics, and advertising work
- How to contact the project about privacy

This file is a project principle and repository policy. It is not a finished privacy notice for a future hosted service.

## Privacy reports

Do not expose more personal information while reporting a privacy problem. Follow the private reporting process in [SECURITY.md](SECURITY.md).
